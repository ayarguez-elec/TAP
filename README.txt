=== Lacroix Electronics - Guide d'installation ===

PREREQUIS:
- Java 17 ou superieur
  Telecharger sur: https://adoptium.net/temurin/releases/?version=17

INSTALLATION:
1. Copier LacroixElectronics.jar et LacroixElectronics.bat dans le meme dossier
2. Double-cliquer sur LacroixElectronics.bat pour lancer l'application

MISE A JOUR:
L'application verifie automatiquement les mises a jour au demarrage.
Acceptez la mise a jour lorsqu'elle vous est proposee.

CONNEXION:
L'application se connecte automatiquement a la base de donnees distante.
Assurez-vous d'avoir une connexion internet.
